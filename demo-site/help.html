Frequently Asked Questions

Open Threats, search for the domain and check the Category and Source columns. Threat Intel means a public blocklist, Policy Rule means an administrator rule and ML Detector means the name looked machine-generated. Use Unblock to add an allow rule.

BIND is not attached (for example when running on Windows), so Sentinel simulates realistic lab traffic. With SENTINEL_MODE=bind on the DNS server, Sentinel manages a real BIND 9: every change is checked with named-checkzone / named-checkconf, written to BIND's files and applied with rndc, and the dashboard shows what BIND actually answered.

The heuristic-v0 model scores names using entropy, label length, digit ratio, vowel ratio, consonant runs, suspicious keywords and high-risk TLDs. Domains above the threshold are blocked when auto-block is on.

DNSSEC adds signatures (RRSIG) to your records so resolvers can prove answers were not forged. Signatures expire, so the zone must be re-signed regularly; BIND does this automatically with dnssec-policy.

An open resolver can be abused for amplification attacks. The ACL limits recursion to your lab networks and Response Rate Limiting caps answers per client. Both are set on the Settings page; Sentinel writes them into BIND's configuration and applies them with rndc reconfig.

Logs are only visible to signed-in users, are deleted after the retention period and client IPs can be anonymized in Settings.
